# 答辩学习路线（航海集市 · 校内二手交易与社团活动一体化平台）

> 用法：每天学一课（约 1 小时）。在学习对话里说「开始第 N 课」，我会结合本项目的真实代码讲解，最后出 3~5 道答辩式小题考你。
> 每课后面的「答辩可能问」要能**用自己的话**说出来，不要背代码。
> 学完一课就在 `[ ]` 里打 `x`。

---

## 先建立全局印象：这个项目长什么样

```
浏览器（Vue 3 页面）
   │  HTTP 请求：/api/xxx，带 JWT 令牌
   ▼
Nginx（frontend 容器）── 提供打包好的页面和 /uploads 图片，把 /api 转发给后端
   │
   ▼
FastAPI 后端（backend 容器）── 校验登录 → 校验参数 → 业务逻辑 → 读写数据库
   │                         └── 需要时调用 DeepSeek 大模型（AI 助手）
   ▼
PostgreSQL 数据库（db 容器）── 17 张表
```

| 层 | 技术 | 在项目里的位置 |
|---|---|---|
| 前端 | Vue 3、Vue Router、Pinia、Axios、Tailwind CSS、Element Plus / shadcn-vue、Vite | `frontend/src/` |
| 后端 | Python、FastAPI、Pydantic、SQLAlchemy 2、PyJWT、bcrypt、cryptography | `backend/app/` |
| 数据库 | PostgreSQL 17、SQL | `backend/sql/schema.sql` |
| AI | DeepSeek 大模型（OpenAI 兼容接口）、Function Calling | `backend/app/core/llm.py`、`api/assistant*.py` |
| 测试 | pytest | `backend/tests/` |
| 部署 | Docker、Docker Compose、Nginx、Linux 服务器、域名与备案 | `docker-compose.yml`、`deploy/`、`frontend/nginx.conf` |

## 第一阶段：基础概念（第 1~4 天）
目标：听懂老师问题里的名词。

- [ ] **第 1 课　Web 应用是怎么工作的**
  前端/后端/数据库各自干什么；HTTP 请求和响应；URL、GET/POST/PUT/DELETE；状态码 200/401/403/404/500；JSON。
  看：浏览器开发者工具的 Network 面板；后端 `http://localhost:8000/docs`。
  答辩可能问：前后端分离是什么？有什么好处？

- [ ] **第 2 课　RESTful API 与接口设计**
  资源和路径怎么命名；统一返回格式 `{code, message, data}`；分页。
  看：`backend/app/main.py`（所有路由在这里注册）、`app/core/exceptions.py`、`app/schemas/common.py`。
  答辩可能问：你的接口为什么统一返回 code/message/data？

- [ ] **第 3 课　Python 必备语法（只学项目里用到的）**
  函数、类、类型注解、装饰器 `@router.get`、`with`、`try/except`、`yield`、虚拟环境 `.venv` 和 `requirements.txt`。
  看：`backend/app/core/security.py`（短小，适合入门）。

- [ ] **第 4 课　JavaScript / Vue 必备语法**
  `const`/箭头函数/解构/`async await`/Promise；`.vue` 单文件组件的 template/script/style 三部分；npm 和 `package.json`。
  看：`frontend/src/components/ItemCard.vue`。

## 第二阶段：数据库（第 5~8 天）——答辩最常被问
- [ ] **第 5 课　关系型数据库与 SQL**
  表、行、列；主键、外键、唯一约束、索引；SELECT/INSERT/UPDATE/DELETE、JOIN、WHERE、ORDER BY、LIMIT。
  看：`backend/sql/schema.sql`。

- [ ] **第 6 课　本项目的数据库设计（E-R 图）**
  17 张表的关系；为什么商品、社团、活动、帖子共用一张 `contents` 表（公共字段 + 子表，便于统一审核、举报、搜索）；一对多、多对多（`club_members`、`activity_signups`）。
  答辩可能问：画一下你的 E-R 图；为什么这样设计？满足第几范式？

- [ ] **第 7 课　ORM：SQLAlchemy**
  ORM 是什么、和手写 SQL 的区别；模型类 `models/`；Session、`commit`、`rollback`；每个请求一个 Session（`db/session.py` 的 `get_db`）。
  答辩可能问：用 ORM 有什么好处？会不会有 SQL 注入？

- [ ] **第 8 课　事务与并发控制（亮点）**
  事务 ACID；两个人同时报名最后一个名额会怎样（超卖问题）；行锁 `SELECT ... FOR UPDATE`（项目里的 `with_for_update`）。
  看：`api/activities.py` 的 `lock_activity`、`tests/test_concurrency.py`。
  答辩可能问：怎么保证活动报名人数不超过上限？

## 第三阶段：后端（第 9~14 天）
- [ ] **第 9 课　FastAPI 基础**：路由、路径参数/查询参数/请求体、自动生成接口文档、`uvicorn` 启动（`run.py`）。
- [ ] **第 10 课　Pydantic 数据校验**：`schemas/` 里的请求/响应模型；为什么后端必须再校验一次（不能只信前端）。
- [ ] **第 11 课　依赖注入**：`Depends`；`api/deps.py` 的 `get_current_user` / `require_admin` / `get_optional_user`。
- [ ] **第 12 课　登录认证（重点）**：密码为什么存 bcrypt 哈希而不是明文；JWT 的三段结构、签发和校验、过期；令牌放在请求头 `Authorization: Bearer`。看 `core/security.py`、`api/auth.py`。
  答辩可能问：JWT 和 Session/Cookie 的区别？令牌被偷了怎么办？
- [ ] **第 13 课　权限与安全**：普通用户/社长/管理员（RBAC）；封禁；敏感词过滤 `core/banned_words.py`；微信号 AES-256-GCM 加密存储 `core/crypto.py`（加密 vs 哈希的区别）；文件上传的安全检查 `api/upload.py`；审计日志 `audit_logs`。
- [ ] **第 14 课　业务流程走一遍**：二手商品 发布→审核→上架→交易意向→接受后交换微信；社团 申请→审批→成员；活动 发布→审核→报名；举报→处理；通知。看 `api/items.py`、`intents.py`、`clubs.py`、`admin.py`。
  答辩可能问：演示一个完整业务流程，状态是怎么变化的？（准备好状态转换图）

## 第四阶段：前端（第 15~18 天）
- [ ] **第 15 课　Vue 3 核心**：响应式 `ref`/`reactive`、`computed`、`v-if`/`v-for`/`v-model`、组件、props 和 emit、生命周期 `onMounted`。
- [ ] **第 16 课　路由与状态管理**：Vue Router（`router/index.js`，路由守卫做登录拦截）；Pinia（`stores/user.js` 保存登录状态）。
- [ ] **第 17 课　前后端通信**：Axios 封装 `api/http.js`——请求拦截器自动带令牌、响应拦截器统一处理错误和 401 跳登录；开发时 Vite 代理 `/api`。
- [ ] **第 18 课　界面与工程化**：Tailwind CSS、组件库（Element Plus、shadcn-vue）、响应式布局（手机能用）；Vite 打包 `npm run build` 产出什么。

## 第五阶段：特色功能（第 19~21 天）——答辩加分项
- [ ] **第 19 课　AI 助手（亮点）**：大模型 API 是怎么调用的（`core/llm.py`，一次 HTTP 请求）；Function Calling（模型决定调用哪个工具查站内数据）；没配 Key 或接口失败时的降级；为什么不把用户隐私发给模型。看 `api/assistant.py`、`assistant_personal.py`、`post_ai.py`。
  答辩可能问：AI 在你系统里具体做了什么？会不会胡说？怎么控制成本？
- [ ] **第 20 课　校园墙**：帖子、评论、点赞、匿名、审核与举报。看 `api/posts.py`、`post_comments.py`、`views/Wall*.vue`。
- [ ] **第 21 课　自动化测试**：pytest、测试数据库、`conftest.py`；测了什么（业务流程、并发、校园墙）。
  答辩可能问：你怎么证明系统是对的？

## 第六阶段：部署上线（第 22~24 天）
- [ ] **第 22 课　Docker**：镜像、容器、数据卷；`backend/Dockerfile`、`frontend/Dockerfile`；Docker Compose 一键启动三个容器（`docker-compose.yml`）。
- [ ] **第 23 课　Nginx 与服务器**：反向代理、静态文件、只开放 80 端口；`frontend/nginx.conf`；Linux 常用命令；`deploy/` 下的脚本（初始化、更新、备份）。
- [ ] **第 24 课　域名、HTTPS 与备案**：DNS 解析；HTTPS 证书；ICP 备案流程；`.env` 密钥为什么不能提交到 Git。

## 第七阶段：答辩冲刺（第 25~28 天）
- [ ] **第 25 课　系统总体设计**：画出系统架构图、功能模块图、E-R 图、核心流程图（论文里都要用）。
- [ ] **第 26 课　技术选型理由**：为什么 FastAPI 不用 Django/Spring Boot；为什么 PostgreSQL 不用 MySQL；为什么 Vue。准备「优点 + 不足 + 改进方向」。
- [ ] **第 27 课　模拟答辩（一）**：我扮演老师连续提问，覆盖第 1~18 课。
- [ ] **第 28 课　模拟答辩（二）**：覆盖特色功能、部署、不足与展望；再练一遍 5 分钟系统演示。

## 答辩高频问题清单（学完要能脱口而出）
1. 系统分几个模块？每个模块做什么？
2. 前后端怎么交互？数据格式是什么？
3. 用户登录是怎么实现的？密码怎么存？
4. 怎么区分普通用户和管理员？
5. 数据库有哪些表？表之间什么关系？
6. 怎么防止活动报名超出人数？
7. 用户隐私（微信号）怎么保护？
8. AI 助手是怎么实现的？
9. 系统怎么部署的？用户怎么访问到？
10. 做的过程中遇到最大的困难是什么？怎么解决的？
11. 系统还有哪些不足？以后怎么改进？
